通知

    下载权限

    扩展自己下载文件（视频 URL 通道、按 URL 取图）时需要域名授权。 本机后端（127.0.0.1 / localhost）安装时已授予，标为「内置」且不可移除； 其他站点可自行添加，也可以随时移除。

    简介

    ABM 是 a browser mcp 的简称。扩展通过 MCP 协议把用户浏览器安全接入 AI， 提供导航、点击、填表、数据提取、网络抓包和文件投递能力。
