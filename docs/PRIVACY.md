# ABM 浏览器助手隐私政策

生效日期：2026-10-21

运营主体：Borgle（个人开发者）

联系邮箱：wu@borgle.io

本隐私政策说明 ABM 浏览器助手（以下简称“本扩展”）如何处理用户数据。ABM 是
**a browser mcp** 的简称。

## 1. 本扩展的定位

本扩展是浏览器端客户端，连接由项目方托管并免费提供的 ABM 服务。扩展不提供
账号注册、AI 模型或 MCP 服务本身。用户通过 ABM 服务创建 API Key，并在扩展
popup 中配置服务地址和 Key。

ABM 托管服务对数据的处理由服务运营方负责；本政策说明扩展端如何处理数据。若
用户将扩展连接到其他兼容服务，该服务的数据处理规则由其运营方负责。

## 2. 在本地存储的数据

本扩展使用 Chrome 本地存储保存：

- ABM 服务端地址；
- API Key；
- 自动重连设置；
- 用户授予的域名权限和连接状态；
- 服务端推送的通知及已读状态；
- 为恢复连接所需的临时会话信息。

API Key 不会作为日志、通知或普通页面数据公开。用户可以在扩展设置中更换或删除
连接配置，也可以卸载扩展以删除 Chrome 为该扩展保存的本地数据。

## 3. 浏览器任务处理的数据

当用户通过 MCP 客户端或 ABM 管理端发起任务时，本扩展可能临时处理：

- 标签页标题、URL、标签分组和窗口状态；
- 页面 DOM、页面变量和用户请求提取的页面内容；
- 点击、键盘、鼠标、滚动和其他用户指定的浏览器操作；
- 网络请求地址、请求或响应信息；
- 用户要求上传到网页的文件、视频和本地路径；
- 任务执行结果、错误信息和必要的诊断信息。

这些数据会按任务需要发送到用户连接的 ABM 服务端，以便 MCP 客户端获取结果。
本扩展不会把这些数据发送到未配置的其他分析、广告或数据经纪服务。

## 4. 文件和视频

扩展可以根据用户任务下载 URL 文件、接收视频桥分片或注入本地路径文件。文件字节
只会用于完成用户指定的网页上传或投递操作。

视频桥暂存位于扩展 service worker 的内存中，最长保留约 30 分钟；service worker
被浏览器回收、到达保留期限或用户清除时会丢失。扩展不会将暂存视频写入持久化
文件存储。

## 5. 可信页面通信

本扩展只允许 manifest `externally_connectable.matches` 中声明的可信页面通过
Chrome 外部消息访问连接配置或视频桥能力。当前可信来源为 ABM 官方域名以及
`localhost`、`127.0.0.1` 本机地址。

受信视频桥可以读取用户连接的服务端地址和 API Key，用于建立同一服务下的视频
投递会话。任意普通网页不能通过该通道获得 API Key。

## 6. 权限用途

本扩展请求浏览器权限是为了完成用户发起的任务：

- 标签页、标签分组和导航权限：执行页面导航和标签管理；
- 脚本权限：读取页面数据、点击、填表、等待元素和注入文件；
- 调试器权限：执行真实输入事件、网络检查和本地路径文件注入；
- 本地存储权限：保存连接配置、通知和用户授权；
- 闹钟权限：在浏览器回收 service worker 后恢复连接；
- 域名权限：连接 ABM 服务或从用户授权的站点下载文件。

可选的“所有网站”权限只会在用户手动开启后生效，用户可以为具体域名单独授权，
也可以在扩展设置中撤销这些权限。

## 7. 数据共享与出售

本扩展不出售用户数据，不将用户数据用于广告，不将用户数据用于信用、贷款、保险
或就业资格判断。

除了将任务所需数据发送到用户连接的 ABM 服务端外，本扩展不会主动向开发者或其他
第三方共享用户数据。ABM 托管服务的数据处理规则由服务运营方负责；如果用户连接
第三方兼容服务，请查阅该服务的隐私政策。

## 8. 数据保留与删除

本地连接配置和通知会保留到用户修改、删除或卸载扩展。视频暂存最长保留约 30 分钟。
浏览器权限可以通过扩展设置或 Chrome 的扩展详情页撤销。

用户可以在 Chrome 中清除扩展数据或卸载扩展。服务端保存的数据由服务端运营方
管理，请按照该服务的账号设置或隐私政策申请删除。

## 9. 安全措施

本扩展将 API Key 保存在 Chrome 扩展存储中，不向普通网页直接暴露，并避免在日志
中记录完整 Key。与 ABM 服务通信使用 HTTPS/WSS；用户应及时撤销不再使用的 API Key
和域名权限。

任何浏览器自动化工具都可能处理敏感页面内容。用户应只在自己信任的浏览器、网站
和 ABM 服务端上执行任务，并及时撤销不再使用的 API Key 和域名权限。

## 10. 儿童隐私

本扩展不是面向儿童的产品，也不主动收集儿童的个人信息。

## 11. 政策更新

当扩展功能、数据范围或权限发生实质变化时，本政策会更新生效日期和相应说明。
用户继续使用更新后的扩展，表示其已了解更新后的数据实践。
